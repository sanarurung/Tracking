# Tracking · 주행 요금계

네이버 지도, 파란 GPS 주행 경로, 상단 거리·누진 요금을 표시하는 iPhone 앱입니다. **iOS 27.0 이상**을 요구하며, 떠 있는 정보 패널과 주행 컨트롤에 네이티브 **Liquid Glass**를 적용했습니다. Xcode 27 이상으로 빌드합니다.

- GPS 진행방향의 전방 시설을 현재 속도 70km/h 이하 500m, 초과 1km 범위에서 자동 시각·음성 안내합니다. 단속 표시는 Liquid Glass 패널에서 분리했습니다.
- 기본 핀과 상시 설명을 작은 안전 표지로 바꾸고 화면상 겹침·줌별 표시 개수를 제한합니다. 카메라·방지턱 위치는 같은 공개 데이터를 사용합니다.
- 앱 시작 시 위치 권한을 요청하고 내 위치를 표시합니다. 주행 시작 전에는 거리를 적립하지 않습니다.
- 주변 2km의 공공데이터 과속·신호 카메라 및 OpenStreetMap 방지턱을 표시합니다. 수집일 2026-10-28, 누락·오차 가능. 소스 ZIP의 SAFETY-DATA.json과 앱 내 데이터 안내를 참고하세요.
- 지도는 화면 전체를 채우고 거리·요금·현재 GPS 속도(km/h)·주행 버튼은 지도 위에 떠 있는 형태로 표시합니다.
- 0~30km: 270원/km, 다음 70km: 250원/km, 100km 초과: 220원/km
- 종료한 주행은 날짜·요금·경로와 함께 자동 보관하고, 상단 기록 버튼에서 다시 봅니다. 새 주행을 시작해도 과거 기록은 남습니다.
- GPS가 정상일 때도 센서 예측을 GPS 위치·속도 정확도와 결합해 보정합니다. 센서 수신 불량 시 GPS만 사용합니다.
- GPS 음영 구간은 가속도계·자이로로 최대 **3분(180초)** 추정합니다. 추정 거리는 요금에 포함되며 따로 표시합니다.
- 센서 편향·회전으로 오차가 누적되므로 실기기 검증이 필요합니다.

전체 Xcode 프로젝트·Swift 소스·테스트는 [DriveMeter-iPhone.zip](DriveMeter-iPhone.zip)에 있습니다. 압축을 풀고 `DriveMeter/DriveMeter.xcodeproj`를 엽니다.

GitHub Actions는 이 소스 압축본을 풀어 빌드·테스트합니다. Actions의 `DriveMeter-unsigned-needs-signing` 결과물은 **서명 전에는 설치할 수 없습니다**. Apple 배포 서명을 설정하면 `DriveMeter-signed-registered-iPhones` IPA가 생성됩니다. [Windows에서 클라우드 빌드·서명하기](CLOUD-BUILD.md)를 참고하세요.

향후 소스 수정 시 압축본 안의 파일을 수정하고 ZIP을 교체하면 같은 워크플로가 빌드합니다.
